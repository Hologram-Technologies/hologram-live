Braille
1 · The insight

An address is already braille

One braille cell holds eight dots, exactly one byte. A 32 byte manifest address is therefore exactly 32 cells, with nothing lost and nothing added. The model's identity can be drawn as a glyph and read back into the same bytes.

2 · Verification you can watch

The bytes resolve into place

Press Verify. While your browser fetches the document and hashes it, the cells search. When the digest is computed, each cell locks left to right and is compared with the pinned address, byte by byte. Green means that byte matched. Every lit dot on screen is a real bit of the result.

3 · The loaders, in Hologram dots

Fifteen motions from the library

The frame sequences come from unicode braille animations. They are drawn here as brand kit dots instead of font glyphs, so they look identical on every platform (Geist Mono has no braille), follow the theme tokens, and respect reduced motion.
