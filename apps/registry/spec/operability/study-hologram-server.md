## 1. What it is

"Hologram Live is a local-first module host … This repository produces two independent products: **Hologram Server**, the standalone `hologram` binary, containing the CLI and background service; **Hologram Desktop**" [read: `README.md:5-8`].

So the product name exists. The product does not yet: it has never been released.

## 2. What is good already

- Refuses unknown configuration. Refuses a public listen without authentication. Bounded bodies, messages and mailboxes. `unsafe` forbidden.
- One binary, no runtime dependencies, starts in about 164 ms and idles at about 12 MB [ran, 2026-09-20: scope document].
- An OpenAPI 3.1 document generated from the code, and an interactive reference, already served. Distribution has neither.
- A verified self-update path.
- Gates on every commit: format, file size, product boundary, clippy pedantic, BDD, smoke.

## 3. The gap list: what a stranger cannot do today

A stranger is someone with Docker installed and ten minutes.

| # | They cannot | Because | Closed by |
|---|---|---|---|
| G1 | download it | no release, no image; the installer needs a Rust toolchain and a 9.5 minute build | FR-S02, FR-S03 |

Fourteen gaps. G5 is the Registry's. The other thirteen are what "a robust and professional standalone product" means, in the concrete.
